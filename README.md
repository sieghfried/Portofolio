# 🌐 Personal Portfolio Website

Selamat datang di repositori web portofolio saya! Situs ini dibangun untuk menampilkan profil, keahlian, proyek-proyek yang telah saya kerjakan, serta cara untuk menghubungi saya.

🎯 **Live Demo:** [https://sieghfried.github.io/Portofolio/]

---

## 🚀 Fitur Utama
* **Desain Responsif**: Tampilan optimal di perangkat mobile, tablet, maupun desktop.
* **Galeri Proyek**: Daftar proyek interaktif yang dilengkapi dengan deskripsi, teknologi, dan tautan.
* **Halaman Tentang Saya**: Informasi singkat mengenai latar belakang dan perjalanan karier saya.
* **Formulir Kontak**: Memudahkan pengunjung untuk mengirimkan pesan langsung ke email saya.
* **Mode Gelap/Terang**: Fitur *toggle* tema untuk kenyamanan visual pengguna.
